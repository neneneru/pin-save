# Pin Save

Pinterestの画像・対応動画を個別保存、またはまとめてZIP保存
保存済みをチェック表示し、一括保存の重複をスキップ

[Chrome ウェブストア](https://chromewebstore.google.com/detail/cibfllieiakohoconingjlpejkdjbnhl) · [プライバシーポリシー](PRIVACY.md) · [お問い合わせ](https://github.com/neneneru/pin-save/issues)
